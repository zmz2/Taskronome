# Windows manual acceptance checklist

Record Windows edition/build, display scale, commit SHA, package SHA-256 and tester name. Mark each result Pass/Fail and attach logs for failures. Use one-second slices for flow checks and longer slices for interruption checks.

## A. Installation and launch

- [ ] Install with a standard user account; no UAC prompt appears.
- [ ] Start-menu shortcut opens one Taskronome window.
- [ ] Launching the executable again activates the existing window and does not create a second timer or tray icon.
- [ ] Portable ZIP runs without installation.
- [ ] Uninstall removes program files and shortcuts but preserves `%LOCALAPPDATA%\Taskronome`.

## B. Task management

- [ ] Create at least three tasks with different hour/minute/second values.
- [ ] Blank/81-character names, 501-character notes, zero, negative-like text, minute 60 and duration 24:00:00 are rejected.
- [ ] Edit, delete, enable/disable, move up/down and double-click edit work.
- [ ] Completed task can be reopened; global completion reset keeps statistics.
- [ ] While rotation is active, editing/deleting/reordering controls are disabled.

## C. Strict round-robin flow

- [ ] Start always opens confirmation for the first task; no task time increases before confirmation.
- [ ] Confirm in the app within 10 seconds; timing starts from the click, not notification arrival.
- [ ] Natural expiry selects the next enabled unfinished task and requires a new confirmation.
- [ ] With one active task, expiry returns to confirmation for the same task.
- [ ] Skip records the event, moves on, and does not mark the task complete.
- [ ] Early completion records only actual worked time and excludes the task from future rounds.
- [ ] Rapidly double-click confirm/pause/skip/complete; no duplicate accounting or multi-task jump occurs.

## D. Presence and notification

- [ ] Let confirmation expire without clicking. At 10 seconds the app enters absence pause and records no task time.
- [ ] Resume after absence starts a fresh full confirmation window for the same task.
- [ ] Windows notification title and body identify the task and 10-second requirement.
- [ ] Clicking the Windows notification restores/focuses Taskronome but does not confirm the task.
- [ ] Disable notification permission in Windows; in-app confirmation, taskbar flashing, sound/tray fallback remain usable and the app does not crash.
- [ ] “Test system notification” reports failure clearly when notifications are unavailable.

## E. Pause and interruption accounting

- [ ] Manual pause freezes remaining time for at least 30 seconds; resume continues the same remainder.
- [ ] During a running task, lock Windows for at least 30 seconds. Unlock leaves Taskronome safely paused; locked time is absent from statistics.
- [ ] Repeat using sleep/wake.
- [ ] Repeat using remote-session disconnect/reconnect when available.
- [ ] Kill Taskronome in Task Manager during a running task, wait, relaunch. It opens in system-pause recovery; offline time is not added.
- [ ] Change Windows date/time forward and backward while running; duration and remaining time do not jump.
- [ ] Suspend or deliberately freeze the process long enough to exceed the heartbeat threshold; it enters system pause and discards the gap.

## F. Window and tray

- [ ] Window is topmost on first launch; setting and `Ctrl+Shift+T` persist across restart.
- [ ] Close during rotation minimizes to tray and does not stop or duplicate time.
- [ ] Tray double-click restores the window; tray pause/resume, topmost and exit commands work.
- [ ] Enter confirms only when waiting and not while typing; Space pauses/resumes only outside text fields; Ctrl+N creates a task only when editing is allowed.
- [ ] Move the window to each monitor, maximize, close/reopen, then disconnect that monitor. Window returns to a visible work area.

## G. Data and statistics

- [ ] Today, 7-day, 30-day and all-time totals match the work segments.
- [ ] CSV opens in Excel with readable Chinese and expected timestamps/durations.
- [ ] Force an invalid `data.json`; original is renamed to `data.corrupt-*.json`, app starts safely and reports recovery.
- [ ] Check `data.json.bak` after two saves.
- [ ] Confirm no network connection or telemetry request is generated by normal operation.

## H. Visual/DPI/accessibility

- [ ] Check 100%, 125%, 150% and 200% scale; no clipped buttons, hidden countdown or unusable dialog.
- [ ] Check keyboard-only navigation and visible focus.
- [ ] Check long task names/notes and narrow minimum window size.
- [ ] Verify high-contrast mode remains legible enough for core actions.
